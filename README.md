# trabalho-estudo-de-caso
Trabalho - Design Profissional
Estudo de Caso - CLÍNICA PETVIDA & ESTÉTICA ANIMAL
A PetVida é uma clínica veterinária de bairro, que oferece serviços como consultas, vacinação, cirurgias, além de banho e tosa.
O principal problema é que todos os agendamentos são feitos através de anotações em papel. Como a empresa está tendo alta demanda pelos serviços oferecidos, este controle não está mais dando conta de manter uma organização, gerando choques de horários, tutores esquecendo data de banho, recepção perdendo tempo procurando informação em arquivos físicos, entre outros problemas.
A solução indicada seria criar um site para que o cliente realize os agendamentos, indicando horários disponíveis, tipo do serviço desejado, raça do pet, entre outras informações, tendo assim um controle mais simplificado e eficiente, além de uma facilidade também para o cliente.
